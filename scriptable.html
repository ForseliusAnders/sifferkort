Widgetskript för Scriptable

Installera Scriptable från App Store (gratis). Skapa ett nytt skript per ruta nedan, klistra in koden och namnge det som rubriken säger.

1. Talet

Namnge skriptet Sifferkort tal

// Sifferkort — visar talet som galler just nu
// Byter var 15:e minut, i takt med hur ofta iOS ritar om widgets.
const d = new Date()
const n = (d.getHours() * 60 + Math.floor(d.getMinutes() / 15) * 15) % 100

// Anpassa storlek efter var widgeten sitter:
// lasskarmens rutor ar sma, hemskarmens stora.
const familj = (typeof config !== "undefined" && config.widgetFamily) || "medium"
const lasskarm = familj.indexOf("accessory") === 0
const storlek = lasskarm ? 30 : (familj === "small" ? 52 : 64)

const w = new ListWidget()
if (!lasskarm) w.backgroundColor = new Color("#111318")
w.setPadding(0, 0, 0, 0)
w.addSpacer()
const t = w.addText(String(n))
t.font = Font.boldSystemFont(storlek)
if (!lasskarm) t.textColor = new Color("#f2f2f2")
t.centerAlignText()
t.minimumScaleFactor = 0.5
w.addSpacer()

// Talet skickas med, sa appen visar exakt det kort widgeten visar
w.url = "https://forseliusanders.github.io/sifferkort/?n=" + n
w.refreshAfterDate = new Date(Date.now() + 60 * 1000)

Script.setWidget(w)
Script.complete()

2. Bilden

Namnge skriptet Sifferkort bild

// Sifferkort — visar bilden for samma tal
// Samma 15-minutersformel som tal-skriptet.
const d = new Date()
const n = (d.getHours() * 60 + Math.floor(d.getMinutes() / 15) * 15) % 100
const nn = String(n).padStart(2, "0")
const url = "https://forseliusanders.github.io/sifferkort/bilder/" + nn + ".png"

const w = new ListWidget()
w.backgroundColor = new Color("#ffffff")
w.setPadding(0, 0, 0, 0)
try {
  const bild = await new Request(url).loadImage()
  // Bilden som widgetens bakgrund = fyller hela ytan utan vita kanter
  w.backgroundImage = bild
} catch (e) {
  const t = w.addText("Bild " + nn)
  t.textColor = new Color("#111318")
  t.centerAlignText()
}

w.url = "https://forseliusanders.github.io/sifferkort/?n=" + n
w.refreshAfterDate = new Date(Date.now() + 60 * 1000)

Script.setWidget(w)
Script.complete()

Så lägger du ut dem

  1. Håll in på hemskärmen → + uppe till vänster → sök Scriptable.
  2. Välj storlek Medium och lägg till.
  3. Håll in den nya widgeten → Redigera widget.
  4. Vid Script: välj Sifferkort tal. Vid When Interacting: välj Open URL och klistra in https://forseliusanders.github.io/sifferkort/?tid
  5. Upprepa på nästa hemskärmssida med Sifferkort bild.

iOS bestämmer själv hur ofta widgets ritas om — oftast var 15:e minut, inte varje minut. Talet och bilden räknas ur klockan, så de visar alltid samma kort som varandra och som appen.
